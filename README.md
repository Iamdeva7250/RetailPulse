# RetailPulse

## AI-Powered Customer Analytics & Demand Forecasting Platform

RetailPulse is an end-to-end Data Science and Machine Learning project
for retail analytics.

## Objectives

- Sales analytics
- Customer analytics
- RFM customer segmentation
- Customer churn prediction
- Demand forecasting
- Inventory risk analysis
- Power BI dashboards
- Streamlit application
- FastAPI prediction API
- MLflow experiment tracking
- Model monitoring
- Docker deployment

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Prophet
- Plotly
- Streamlit
- FastAPI
- Power BI
- MLflow
- Docker

## Dataset

Online Retail II Dataset

Source:
UCI Machine Learning Repository
